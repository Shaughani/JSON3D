# Saved atlas files

Canonical `.atlas.json` exports for the TAP Architecture Atlas viewer.

| File | Description |
|------|-------------|
| `blank-atlas.atlas.json` | Empty starter atlas (one root node) — **Open** this to begin a new system |
| `TAP-Codebase.atlas.json` | **Codebase map** — repos, packages, imports (see `Scraper System/docs/`) |
| `TAP-System-Atlas.atlas.json` | Same graph as embedded default in `index.html` (production digital twin) |

Open in the viewer: **Open** → select a file from this folder, or drag it onto `index.html` in a browser that supports file open.
